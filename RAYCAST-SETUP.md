# Raycast setup

Raycast replaces Spotlight. Config is synced via Raycast's own cloud sync (not tracked in git).

## First-run

1. Unbind Spotlight: **System Settings → Keyboard → Keyboard Shortcuts → Spotlight**, disable `Show Spotlight search`.
2. Launch Raycast. Set hotkey to `Cmd+Space`.
3. Sign in to enable settings sync across machines.

## Recommended extensions

Install via Raycast Store (`Cmd+Space` → Store → search):

- **Clipboard History** — built-in, enable history.
- **Calendar** — native integration for today's events.
- **1Password** — quick-open vault items.
- **GitHub** — search repos/PRs/issues.
- **Brew** — install/upgrade from Raycast.
- **Kill Process** — activity-monitor replacement.
- **Color Picker** — menubar color picker.

## Don't install

- **Window Management** extension — Aerospace owns tiling/movement. Keep those bindings free.
